# LogosKittens

Local cognitive middleware. The same five primitives drive the web buddy now and a physical robot later: `Situation`, `Task`, `Actor`, `GroupSolution`, `ElementSolution`. The cognitive core stays unaware of pixels, servos, and ROS.

## Read order

1. `free_conv.md` is the design of record for the talk: free speech, raw material, the two prompts, the trainer, and the later stages. `group.md` is the design for Savelij, Rob, and the background-expert shape. It does not open `buddy-two`.
2. `logoskittens_architecture.md` for the ontology, the protobuf, and the robot transition. Sections 2, 6, and 8 stay as written. Sections 3, 5, and 12 match `free_conv.md`.
3. `work-plan.md` for what to build. Implement only the next incomplete stage. Mark a stage done in that file, in the same change, only after its exit criteria pass.
4. `cerm_architecture_document.md` is the predecessor spec (LogosCat). When it disagrees with the two documents above, follow them.

`flow.md`, `impl-conversation-oct-16.md`, and `conversational_architecture.md` are retired. `free_conv.md` replaces them. Do not follow them.

Keep design detail in `free_conv.md` and the architecture doc. Keep sequence and exit criteria in `work-plan.md`. This file stays short.

## Invariants

- The cognitive hub emits semantic and affective directives. Pixel and CSS mappings live in `virtual-stage`. Token-to-action names for a connected body live in `bot-link`. Servo, Pulse, and ROS stay on the robot. A voiced turn keeps one face. Web mode, the switch off, records and plays in the browser. Botnet mode, the switch on, delivers PCM to an attached buddy and the page stays quiet.
- `ElementSolution` on the wire is protobuf package `cerm.execution.v1`, matching architecture §6, including `EMOTION_ENCOURAGEMENT` and `EMOTION_FRUSTRATION`.
- LLM calls stay inside `cognitive-hub`. The client is `httpx`. Local default is Ollama. Remote is Grok (`XAI_API_KEY`, base URL `https://api.x.ai/v1`). The key stays in the environment, on the server.
- The live talk is free speech in a language parameter. Live packs are `en`, `nb`, `uk`, `de`, and `he`. One active buddy (`buddy-one`). `buddy-two` stays in the actor model and is inactive. `teacher-one` is Savelij. He is not a second buddy. He speaks only when Rob has a correction. A new language is files under `config/` and a click in the Talk panel. Finish the open stage before adding a second buddy. The LogosCat client is an app-token connection and a workspace-session import. It does not mark item 9 done.
- Human speech errors are stored as heard and are not corrected.
- Persistence of the live talk is one SQLite file via SQLModel, WAL mode.

## Layout

```
proto/            shared Protobuf contracts
audio-engine/     Piper TTS. Speech recognition runs on the host GPU
cognitive-hub/    FastAPI, LangGraph, SQLModel
bot-link/         player sockets the hub imports. Not a second server.
virtual-stage/    Vite, React, TypeScript
config/           languages, raw materials, prompts, sim matrix, players
shared/           generated stubs and types used by more than one service
tests/
```

One service per directory. Shared contracts live in `proto/`.

Simulation trials live in `simulations/` in this repo. Commit `decision.md` and `scores.json`. `.gitignore` drops traces, round config copies, call logs, sqlite, audio, and model binaries.

## Stack

- Python 3.11+, FastAPI, LangGraph, Pydantic v2, SQLModel, SQLite
- Host whisper.cpp + Silero VAD. The launcher picks Metal, CUDA, Vulkan, or CPU. Piper TTS in `audio-engine`. HTTP: `POST /transcribe`, `POST /synthesize`
- Vite, React, TypeScript, Tailwind, SVG avatars
- Docker Compose for the local loop

## Choices

- `AudioPayload.precomputed_audio_pcm` is signed 16-bit little-endian mono PCM at 22050 Hz. The audio engine's HTTP `/synthesize` response is a WAV wrapper of that PCM. The hub strips the header before encoding protobuf.

A reply that copies the human's sentence is cut back to the words after the copy, and if the line still misses the subject it is asked again in the buddy's own words. Each turn adds `language_specifics`: person `1st`, and that profile's gender. Both speak as I. The language-pack `buddy_voice` is only the fallback when a turn has no profile. `buddy-two` stays inactive. A voice id may name a Piper speaker after `@`. On Norsk that is Lucas or Ingrid, whichever is open. `no_NO-nvcc-medium` stays in the image and is not selected. - Speech recognition is one host whisper.cpp process. English uses `RECOGNITION_MODEL` from `.env_recognition` (default `small.en`) with `-l en`. The launcher downloads `ggml-<name>.bin`. Norsk (`nb`) uses NbAiLab `nb-whisper-large` with `-l no`. Ukrainian (`uk`) uses `ggml-large-v3-turbo.bin` with `-l uk`. German (`de`) uses the same `ggml-large-v3-turbo.bin` with `-l de`. Hebrew (`he`) uses ivrit.ai `whisper-large-v3-turbo-ggml` saved as `ggml-ivrit-large-v3-turbo.bin`, with `-l he`. A language file other than `en` and `nb` that names `whisper.weight_file` and `whisper.url` is downloaded once by the launcher (`scripts/extra_weights.py`) and passed to the supervisor as `--model uk=PATH` and `--model de=PATH`; a shared weight is downloaded once. `ggml-nb-whisper-medium.bin` stays on disk and is not loaded. `./scripts/host_whisper.sh` on macOS and Ubuntu, and `.\scripts\host_whisper.ps1` on Windows, start `scripts/whisper_supervisor.py`, which serves recognition on port 8082 and a language switch on port 8083 (`POST /switch` with `{"language":"en"}`, `{"language":"nb"}`, `{"language":"uk"}`, `{"language":"de"}`, or `{"language":"he"}`). A switch re-reads `config/languages` before it checks the id, then stops the current process before it loads the other weight. Silero VAD stays on, with a minimum speech of 100 ms, a minimum silence of 400 ms, and 300 ms of padding. The supervisor starts on `en` when `config/languages/en.json` is present. The launcher prints the backend: `metal` on macOS; on Linux and Windows `cuda` when `nvidia-smi` and `nvcc` work, otherwise `vulkan` when a Vulkan GPU is present, otherwise `cpu`. A CPU start prints that the GPU is not in use. Build directories are `build-metal`, `build-cuda`, `build-vulkan`, and `build-cpu`. The audio container forwards `/transcribe` and speaks with Piper. Docker on macOS cannot see the Apple GPU, so recognition stays on the host on every OS.
- LLM client is `httpx`. Grok uses `POST /v1/chat/completions` (model `grok-4.7`, base `https://api.x.ai/v1`). Local Ollama uses `POST /api/chat` with `format: json`, `num_ctx` 4096 (`MAX_NUM_CTX` in `llm.py`; at 2048 a Ukrainian turn lost its system prompt to truncation), and `LLM_THINK` (`off` by default; also `on`, `low`, `medium`, `high`, `max`). Grok reads the same variable as `reasoning_effort` (`low`, `medium`, `high`, `xhigh`; empty means `high`). `grok-4.7` cannot turn reasoning off. The default local model is `qwen3:8b`. Practice reads `.env` (`LLM_BACKEND`, `LLM_MODEL`, `GROK_MODEL`). Training reads `.env_training`: `BACKEND_SIM_TALK` for the simulated talk and `BACKEND_JUDGE_PROPOSER` for the judge and the proposer. Each is `local` or `grok`, with its own base URL, model, and API key.
- BOB (`buddy_out_brain`) is a second loop inside the hub. It does not speak and it is not `buddy-two`. After the buddy line is sent, it may store one steer for the next local call. Settings are `config/bob.json` (`enabled`, `backend`, `base_url`, `model`, `think`, `timeout_s`, `steer_max_chars`, `every_n`, `qa`). The shipped backend is `xai`: `POST /v1/chat/completions`, model `grok-4.7`, think `low` as `reasoning_effort`. The key is `BOB_API_KEY`, or `XAI_API_KEY` when that is empty. Empty `BOB_ENABLED`, `BOB_BACKEND`, `BOB_BASE_URL`, `BOB_MODEL`, `BOB_THINK`, `BOB_TIMEOUT`, `BOB_QA`, `BOB_API_KEY`, `BOB_STEER_MAX_CHARS`, and `BOB_EVERY` leave the json value. `every_n` is 3: one call after every third buddy reply, and a late result from an older call is dropped only when a newer call starts. BOB does not read `LLM_BACKEND`. The prompt is `config/prompts/bob_{language}.md` (`bob_en.md`, `bob_nb.md`, `bob_uk.md`, `bob_de.md`, `bob_he.md`) and is not on the trainer allow-list. Norwegian, Ukrainian, German, and Hebrew prompt files are not on that list either. The watch text includes the buddy's mood, stance, likes, and summary. A steer is a nearby subject in that character, not a forced mention of steak or a fight. The same message may name one pose: agreement when it agrees or answers yes, disagreement when it disagrees or answers no, frustration when the situation is sad or disturbing, curiosity when it asks a question. She plays that one pose after the voice on the reply that uses the steer, and does not repeat it. When the human asks a question, greets, or names no subject, the steer is one question about the talk. QA defaults off. The local reply answers the human and then uses the hint. A question hint is asked after that answer. The part that counts is the last sentence of the hint, and a theme word such as fjord does not count. A reply that misses that new word is asked once more. While QA is on, `altered by BOB` appears only when the spoken line used one of those new words, then `Suggested alteration:` with the steer. A steer still waiting shows `Next suggestion:`. The same switch lists the card's important words under Send as `Outside the theme`. Speak asks the attached buddy to record.
- Rob is the background expert for the teacher. He does not speak and he is not `buddy-two`. Settings are `config/rob.json`. The shipped backend is `xai`, model `grok-4.7`, think `low`. The key is `ROB_API_KEY`, or `XAI_API_KEY` when that is empty. `every_n` is 2, 3, or 4 human sentences, default 3. He reads only the stretch since his cursor and returns silence or one sentence. That sentence is what Savelij says. There is no second rewrite. The profile is `config/teachers/savelij.json`, actor `teacher-one`. He is the teacher for every live language. English voice `en_US-ryan-medium`. Norsk voice `no_NO-talesyntese-medium`. Ukrainian voice `uk_UA-ukrainian_tts-medium@mykyta`. German voice `de_DE-thorsten-medium`. Hebrew voice `he_IL-saspeech-medium`. He is not listed with the buddies. The prompts are `config/prompts/rob_en.md`, `rob_nb.md`, `rob_uk.md`, `rob_de.md`, and `rob_he.md`. Neither is on the trainer allow-list. Teacher mode is stored on the session as `relaxed` or `pedantic`. Relaxed is the default and speaks that one sentence at once. Pedantic runs after `pedantic_every_responses` human responses, shipped as 2, and judges every human sentence in the stretch. Its prompts are `config/prompts/rob_pedantic_en.md`, `rob_pedantic_nb.md`, `rob_pedantic_uk.md`, `rob_pedantic_de.md`, and `rob_pedantic_he.md`, also off the allow-list. A correction stores the explanation and its PCM. A red Correction button sits on that human sentence. Hear plays the stored PCM in the browser. Pedantic does not emit a teacher solution and does not deliver that PCM to the teacher body. QA on shows Rob's sentence, or `nothing to correct`, in its own block. QA off still shows the spoken line under his name. The stage shows his card beside the buddy. The Talk panel lists him under Teacher, not under Buddy. His body package is `/home/jetson/yahboomcar_ros2_ws/yahboomcar_ws/src/lk_body`. It plays on the USB PnP speaker port and does not open a microphone. `lk_bot_mode enter` starts it. `leave` stops it and does not touch the car's bringup. The dial key is `SAVELIJ_HUB_WS`. Web mode plays his PCM in the browser. Botnet mode delivers it only to role `teacher`. One teacher may attach beside one buddy. A second teacher is refused. His body package is later. `group.md` is the design.
- Wren is the background orchestrator for a talking game. He does not speak and he is not Bob, Rob, or Savelij. Settings are `config/wren.json`. The shipped backend is `xai`, model `grok-4.7`, think `low`. The key is `WREN_API_KEY`, or `XAI_API_KEY` when that is empty. Empty `WREN_ENABLED`, `WREN_BACKEND`, `WREN_BASE_URL`, `WREN_MODEL`, `WREN_THINK`, and `WREN_TIMEOUT` leave the json value. Wren does not read `LLM_BACKEND`. The call is `llm.complete_xai`. A game session does not call Bob or Rob. Free speech does not call Wren. The plugin host is `cognitive-hub/src/logoskittens/games/`. Free speech is an empty `game_id`. `probe` stays unlisted. The listed games are the built rows of the `games.md` Catalogue, each a manifest in `config/games/` and one line in `games/registry.py` `builtin()`. Game names are one token ending in Game. Ids stay short. `games.md` is the design.
- Talking games, choices from the `games.md` Build order. Source and target languages come from LogosCat `GET /api/language-settings` through the hub route `GET /logoscat/language-settings` (no token, or LogosCat down: the local sets `en`/`nb`/`uk`/`de`/`he` sources and `en`/`nb`/`uk`/`de`/`he` targets; `no` maps to `nb`; `ukr` and `uk-UA` map to `uk`; `deu`, `ger`, `de-DE`, `de-AT`, and `de-CH` map to `de`; `heb`, `iw`, and `he-IL` map to `he`; at most 4 targets). Ukrainian lists the same games as English. Its game prompts `config/prompts/games/*_uk.md` are compact English that demands Ukrainian, not Russian, addresses the learner as «ти», and keeps Wren's lines free of gendered first-person forms, because the deck does not know the buddy. Each manifest carries `uk` titles, summaries, closings, and option labels; the closings are gender-neutral. German lists the same games too. Its game prompts `config/prompts/games/*_de.md` are compact English that demands German and addresses the learner as «du»; each manifest carries `de` titles, summaries, closings, and option labels. Hebrew lists the same games. Its game prompts `config/prompts/games/*_he.md` are compact English that demands Hebrew without niqqud and addresses the learner with plural or neutral forms, because the learner's gender is unknown; its closings use plural «אתם» forms. The page keeps them in `localStorage` under `logoskittens.source` and `logoskittens.targets`. `WREN_PREFETCH` (empty leaves `config/wren.json` `prefetch`, shipped true) prepares the next round when the last target turns active. Every game turn prints one stderr line `game timing id=… stt= check= judge= partner= tts= first_audio=`, and a prepare prints `game timing prepare id=… wren=`. Deck lines are voiced once in the background into a per-session cache of 64 entries and 20 MB. In OverhearGame only, Savelij speaks Wren's deck lines as `teacher-one` with role `teacher`; Rob still does not run in a game. ReactGame sends mimic tokens from `config/mimic_tokens.json` with its stems. The phase 2 deck games are thin subclasses of `games/deck_game.py`. The Read the text window reads `GET /materials/{id}?language_id=` (ids limited to letters, digits, `_`, `-`); manifest `read_text` (`play` or `between`) decides when the game card offers it.
- A player row in `config/players.json` may carry `volume`, a factor per language for that body only (above 0, at most 2). `bot-link` `deliver()` scales the PCM it sends that body. Masha ships `{"de": 0.7}`: German is 30% quieter on her speaker. The page and Savelij are unchanged.
- When the attached buddy's recording reaches the hub, `bot-link` `cue()` sends her one pose with no PCM (`LISTEN_POSE`, empty means `curiosity`, `off` sends nothing). It carries no speaking action, takes no mouth slot, and is skipped while she is speaking.
- WebSocket framing is JSON (`session_id`, `transcript`, base64 `solutions`). Each solution is an `ElementSolution` protobuf payload. One solution per buddy turn, actor `buddy-one`. A teacher correction is a separate message, actor `teacher-one`.
- Language is a parameter. Prompt files are `config/prompts/prompt-of-subject-creation_{language}.md` and `config/prompts/ongoing_instruction_prompt_{language}.md`. English files end in `_en`. Norwegian Bokmål files end in `_nb`, Ukrainian files end in `_uk`, and German files end in `_de`, and Hebrew files end in `_he`; none copies the English text. The Ukrainian buddy and subject prompts (`ongoing_instruction_prompt_uk.md`, `prompt-of-subject-creation_uk.md`) and its `language_specifics` are compact English that demands Ukrainian output, because Cyrillic costs two to three times the tokens. The German buddy and subject prompts follow that same compact English shape and demand German; Bob, Rob, and the pseudo-human prompts for `de` are in German. Every Hebrew prompt, Bob and Rob included, is compact English that demands Hebrew without niqqud. The buddy prompt's `recent` block keeps the newest lines within 900 characters (`RECENT_CHARS`). A pack with `reask_soft_misses: false` (`nb`, `uk`, `de`, `he`) keeps the first reply on a soft miss (theme story, missed hint, a line the word checks think ignores the human) and spends a second call only on third person or a copied sentence; English keeps every re-ask. The Talk panel lists English, Norsk, Українська, Deutsch, and עברית. While the chosen source is right to left (`isRtl` in `virtual-stage/src/languages.tsx`: `he`, `ar`, `fa`, `ur`, `yi`), the page sets `dir="rtl"` on the document and mirrors; the page uses start and end classes (`text-start`, `ms-`, `me-`, `border-e`), never left and right. A click reloads the mounted config, maps the buddy by gender (Peter to Lucas, Mary to Ingrid), and switches the recognizer. Raw material files are `config/raw_materials/{language}/{id}.txt`. The shared material ids are `norway_vacation_tunnels_fjords` (`Ferie i Norge` on `nb`), `friendly_chat` (`Friendly chat` on `en`, `Vennlig prat` on `nb`, `Дружня розмова` on `uk`, `Freundliches Gespräch` on `de`, `שיחה ידידותית` on `he`), and `spider_brackfast` (`Spider Brackfast` on `en`, `Edderkoppfrokost` on `nb`, `Павучий сніданок` on `uk`, `Spinnenfrühstück` on `de`, `ארוחת בוקר של עכבישה` on `he`). The Norway file is `Відпустка в Норвегії` on `uk`, `Urlaub in Norwegen` on `de`, and `חופשה בנורווגיה` on `he`. The default stays the Norway file. A user may add any number of materials per live language in the Raw material panel (Add material, ✎ edit, × delete). They are `OwnMaterialRow` rows in the hub SQLite file, ids `own-…`, and never leave the hub. Routes are `POST /materials`, `PUT /materials/{id}`, and `DELETE /materials/{id}`, own ids only. A title is at most 120 characters, and the text has at least two sentences and at most 20,000 characters. The language is fixed at creation. An edit reaches new talks and decks only. Edit and delete are refused while the running talk uses that material. They load through `MaterialLibrary` like files, so the talk, Bob, Rob, and every game use them. The subject card also keeps `important_words`: practice words from those sentences that the theme would drop. On some content replies the buddy may use one of them. A question, a greeting, a passive line, and a steered turn do not name one. A word the buddy has already said is not named again. Leaving it out is allowed. An older session with no list stays empty until the subject is built again.
- The live graph is `build_prepare_graph` (summarize once) then `build_turn_graph` (`speak`, `compile`) in `graph.py`. There is no assess node and no second speaker in that graph. In relaxed mode Savelij's line is compiled after it, only when Rob returned a sentence. Pedantic mode stores the explanation and its PCM and does not compile a teacher solution. The session scene id is `free_speech`. `joint_hunting` is reserved and rejected at start. Material mode `detached` reads files. `attached` is the LogosCat slot and does not switch the live loop. Actor files are `config/actors/`. Open role pairs are `config/roles.json`. Mimic tokens the hub may send are `config/mimic_tokens.json`. A body shape without hardware is `bodies/lk_body/`. `GroupSolution.protocol` is `free_speech`.
- `python -m logoskittens.sim improve run` scores the three frozen scripts in `config/sim/matrix.json`, writes one proposal, and waits. The proposal may replace the full text of one of the two `_en` prompt files (mutation key `body`). The judge and the proposer use `BACKEND_JUDGE_PROPOSER` from `.env_training`. Each call is one flushed line on stderr and in the improve `calls.log`: the POST as it starts, then the HTTP status, latency, and token counts. A Grok call waits up to 420 seconds and is tried once more if the read times out. The simulated talk uses `BACKEND_SIM_TALK` from that same file. `approve` replays under `simulations/` and copies a prompt back into `config/prompts/` only when a score rose, none fell, and no fail-flag is set, then asks for the next proposal. `reject` records the refusal and does not write a new proposal. A code edit is out of band. `sim talk` runs a pseudo-human and is not the accept gate.
- LogosKittens never asks for a LogosCat password. The user logs in on LogosCat, opens Settings, Connected apps, and creates a personal app token (`lkc_…`, read-only scopes `sessions:read` and `settings:read`, 30, 90, or 365 days, revocable). Connect LogosCat pastes it into the page, and the hub checks it with `GET /api/app-token/whoami` (`POST /logoscat/connect`; `GET /logoscat/info` gives the Connected apps link). There is no login, logout, or ALTCHA route. The page keeps `{token, user, expiresAt}` in `localStorage` under `logoskittens.logoscat`. Disconnect forgets it on the page only. Any 401 clears it and says the token expired or was revoked. LogosCat rate limits app tokens per user and per IP, so the hub client makes one call at a time, caches whoami until a 401, language settings for 10 minutes, and the session list for 60 seconds, and does not call a path again before its `Retry-After`. An import reads at most 50 recap pages; a 429 partway keeps the pages already read. `MODE=dev` (the default) calls `http://localhost:8080`. Inside the hub container that is `http://host.docker.internal:8080`, because the container's own port 8080 is the hub. `MODE=prod` calls `https://logoscat.com`. The page does not call LogosCat itself. The hub does not pretend to be the Chrome extension. Workspace sessions opens a list. Choosing one downloads `text_input` lines only, stores them as `logoscat-{workspaceSessionId}`, and selects that row in the Talk panel. Start begins the talk. `en` stays English. `no`, `nb`, and `nob` become `nb`. `uk`, `ukr`, and `uk-UA` become `uk`. `de`, `deu`, `ger`, and `de-DE` become `de`. `he`, `heb`, `iw`, and `he-IL` become `he`. One live language switches the talk. A mix keeps the lines that match the talk already open. The session name stays in the raw-material list, connected or not, until its delete button removes it from the database. File materials still load when LogosCat is down. `attached` stays unwired.
